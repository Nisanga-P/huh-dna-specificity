# [Machine Learning for Protein-DNA Specifity Prediction]

HUH-endonucleases are a superfamily of enzymes that cleave ssDNA, and play an important role in viral (rolling-circle) replication, bacterial conjugation and the modern biotech tool HUH-tags. The project develops a ML model that predicts the specifity between HUH endonuclease amino acid sequence and the corresponding ssDNA ori.
